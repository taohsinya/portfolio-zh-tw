# 行銷專案

這是我 12 年來主導的行銷工作，有些在投入 AI 之前，有些和 AI 工作同時進行。每一頁都用同樣的架構：問題、我做了什麼、成果，以及我學到的事。

## 我做行銷的方法

1. **找到利基。** 找出大型業者沒有好好服務的一群人。
2. **用一句話講清楚。** 如果訊息能說明你為什麼不一樣，每支廣告、每則貼文都會更好做。
3. **選對管道。** 在地團隊、網紅、社群、電視或公車廣告：那群受眾真正信任什麼，就用什麼。
4. **衡量。** 追蹤少數幾個重要數字，例如廣告投資報酬率、每次安裝成本或入金使用者數，再把錢移到有效的地方。
