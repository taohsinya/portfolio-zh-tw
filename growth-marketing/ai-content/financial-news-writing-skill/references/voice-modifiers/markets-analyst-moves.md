# Voice Modifier: Markets > Analyst Moves

## Required Data Table
```
| Field | Value |
|-------|-------|
| Analyst | [Full Name] |
| Firm | [Firm Name] |
| Previous Rating | [Rating] |
| New Rating | [Rating] |
| Previous PT | $X |
| New PT | $X |
| Current Price | $X |
| Implied Upside/Downside | X% |
```

## Explanation Depth: LOW
Reader understands ratings. Focus on: the reason for the change (one sentence), the key metric driving conviction, and whether this is consensus or contrarian.

## Tone Calibration
- The analyst's thesis IS the story. Represent it accurately, don't editorialize.
- If multiple analysts move on the same name, lead with the most influential (bulge bracket > boutique).
