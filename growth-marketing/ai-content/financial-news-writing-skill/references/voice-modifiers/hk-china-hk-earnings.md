# Voice Modifier: HK & China > HK Earnings

## Uses Model A (Wire)

## Required Data
- Company name (English + Chinese) + ticker (XXXX.HK)
- Reporting period and fiscal year
- Revenue: actual (HK$ or RMB) + YoY change %
- Net profit: actual + YoY change %
- EPS: actual
- Dividend: interim/final per share (HKD) + payout ratio
- One key operating metric (see sector table in data-requirements.md)
- Stock price reaction: % change + direction
- Consensus comparison if available

## HK Earnings-Specific Rules
- Currency: report in the company's reporting currency (most use HKD or RMB). Convert to USD only for deal-size context.
- Accounting standard: note HKFRS/IFRS if relevant to comparison
- Interim vs final results: HK companies often report semi-annually — specify "interim" or "annual" clearly
- Dividend: HK investors care about dividends — always include if declared
- H-share vs red chip: note corporate structure type if it affects taxation or regulation

## Explanation Depth: LOW
Wire speed. Numbers first. One quote from CEO/CFO. Segment breakdown if conglomerate.
