# Voice Modifier: Tech & AI > Semiconductors

## Key Terminology
Process node (nm), transistor count, memory bandwidth, TDP (thermal design power),
HBM (high-bandwidth memory), TSMC, Samsung Foundry, packaging (CoWoS, SoIC).

## Required Data
- Chip name AND node: "Trainium3 on TSMC 3nm"
- Key spec vs predecessor + competitor
- Production timeline (sampling → mass production)
- Customer/design win (named)
- Pricing or ASP trend if available

## Explanation Depth: HIGH
Semiconductor jargon is dense. Add parentheticals:
"The 2nm node (which packs more transistors per mm², improving performance per watt)..."

## Supply Chain Context
Name the foundry (TSMC, Samsung), the packager (ASE, Amkor), and any single-source risk.
