# Mandatory Data Points by Sub-tag

Every sub-tag has a checklist of data points that MUST appear in the article.
If a data point is unavailable, write "not yet disclosed" or "data pending" — never
substitute with vague language.

---

## Markets

### Earnings
- [ ] Company name + ticker + exchange
- [ ] Quarter and fiscal year (e.g., "Q4 FY2025")
- [ ] Revenue: actual dollar amount
- [ ] Revenue: vs consensus estimate (beat/miss by $X or X%)
- [ ] Revenue: vs prior year quarter (YoY change %)
- [ ] EPS: actual amount
- [ ] EPS: vs consensus estimate
- [ ] Guidance: raised / lowered / maintained + specific numbers
- [ ] One key operating metric (varies by sector — see sector table below)
- [ ] Stock price reaction: % change + direction

### Analyst Moves
- [ ] Analyst full name
- [ ] Firm name
- [ ] Previous rating → New rating
- [ ] Previous price target → New price target
- [ ] Current stock price
- [ ] Implied upside/downside %
- [ ] Key reason for the change (one sentence)

### Market Moves
- [ ] Index name(s) affected (S&P 500, Nasdaq, Dow, Russell)
- [ ] Exact point/percentage change
- [ ] Closing level
- [ ] Sector leaders and laggards with % moves
- [ ] Volume vs average (above/below by X%)
- [ ] Primary catalyst (named event, not "market sentiment")

### IPO & M&A
- [ ] Deal value (total enterprise value or equity value)
- [ ] Payment structure (cash, stock, mix — with ratio)
- [ ] Premium to undisturbed price (% premium)
- [ ] Expected closing timeline
- [ ] Regulatory approvals needed
- [ ] Strategic rationale (one sentence with specifics)

### Shareholder Actions
- [ ] Action type (buyback, dividend, split, insider trade)
- [ ] Dollar amount or share count
- [ ] As percentage of outstanding shares or market cap
- [ ] Timeframe for execution
- [ ] Stock price reaction: % change

## Economy

### Central Banks
- [ ] Institution name (Fed, ECB, BoE, BoJ, PBoC)
- [ ] Decision: rate level + change (e.g., "held at 5.25-5.50%")
- [ ] Vote split if available (e.g., "9-3 with three dissents")
- [ ] Key quote from statement or press conference
- [ ] Forward guidance summary (hawkish/dovish + specific wording)
- [ ] Market reaction: at least 2 assets (e.g., "2Y yield +8bps, S&P -0.4%")
- [ ] Next meeting date

### Economic Data
- [ ] Data release name (CPI, NFP, GDP, PMI, etc.)
- [ ] Actual value
- [ ] Consensus estimate
- [ ] Previous period value
- [ ] Headline vs core (for CPI/PCE/PPI)
- [ ] Key component breakdown (1-2 most important sub-indices)
- [ ] Market reaction: at least 1 asset move

### Trade & Tariffs
- [ ] Countries involved
- [ ] Specific tariff rate(s) or trade measure
- [ ] Products/sectors affected
- [ ] Dollar value of affected trade
- [ ] Effective date
- [ ] Retaliatory measures (if any)

### Geopolitics
- [ ] Countries/parties involved
- [ ] Specific event or escalation
- [ ] Date of event
- [ ] Commodity price impact (oil, gold, etc.)
- [ ] Market/currency impact
- [ ] Historical comparison or precedent (one sentence)

### Regulation
- [ ] Regulatory body name
- [ ] Specific rule/action
- [ ] Companies/sectors affected
- [ ] Effective date or timeline
- [ ] Financial impact estimate (if available)

- [ ] Affected tokens/exchanges/protocols
- [ ] Fine amount or penalty (if enforcement)

## Sector-Specific Operating Metrics (for Earnings Articles)

When writing a Model A earnings article, include the ONE most important
operating metric for the sector:

| Sector | Key Operating Metric |
|--------|---------------------|
| Semiconductor | Data center revenue %, wafer starts, ASP trend |
| Cloud | Remaining performance obligations (RPO), cloud revenue % |
| SaaS | ARR, NRR, customer count |
| Oil & Gas | Production BOE/d, breakeven price, hedging % |
| Mining | AISC per oz, reserves, production guidance |
| Airlines | Load factor, CASM-ex, RASM |
| Banks | NIM, CET1, provision for credit losses |
| Insurance | Combined ratio, written premium growth |
| REIT | FFO/AFFO per share, occupancy, same-store NOI growth |
| Pharma | Pipeline milestone, peak sales estimate |
| Retail | Same-store sales growth, inventory days |
| Telecom | ARPU, churn rate, subscriber adds |
| EV | Deliveries, ASP, gross margin per vehicle |
