# Banned Words, Phrases, and Structures

Zero tolerance. Any appearance in final draft = article fails quality check.

---

## Tier 1: Hard Ban — Universal (delete or replace, no exceptions)

| Banned | Replace With |
|--------|-------------|
| delve | explore, examine, look at |
| realm | area, field |
| tapestry | (delete) |
| landscape | market, sector, environment |
| leverage (verb) | use |
| utilize | use |
| robust | strong, reliable, or be specific |
| seamless | smooth, easy |
| comprehensive | full, complete |
| cutting-edge | new, or describe what's new |
| holistic | complete, full |
| synergy | (delete, describe specific benefit) |
| paradigm | model, approach |
| empower | be specific about what capability |
| innovative | describe the actual innovation |
| transformative | changed, improved |
| spearhead | lead |
| pivotal | important, or be specific |

## Tier 1-E: House-Style Bans (found by auditing earlier AI drafts)

| Banned | Replace With |
|--------|-------------|
| signaling | "X because Y" — state cause directly |
| positioning (it to) | (delete — state what the company is doing) |
| underscores / underscoring | shows, or just state the fact |
| sends a clear message | (delete — let readers judge) |
| amplifies / amplifying | pushed X down 3%, increased Y by Z% |
| validates / validation | confirmed by, supported by |
| amid / amidst | as, after, because, during, while |
| catalyst | name the specific event |
| sparked / sparks | caused, led to, triggered |
| bolsters / bolstering | strengthens, supports |
| poised (to) | expected to, likely to |

## Tier 2: Banned Phrases (delete entirely)

### Throat-Clearing
- "It's important to note that..."
- "In today's [X] landscape..."
- "Let's dive/delve into..."
- "Without further ado..."
- "In this article, we will..."
- "It's worth mentioning that..."
- "It goes without saying..."
- "As we all know..."

### Empty Hedges
- "To be fair..." / "To be honest..."
- "At the end of the day..."
- "When it comes to..."
- "In terms of..."
- "With respect to..."

### AI Enthusiasm
- "This is a game-changer"
- "...and that's a good thing!"
- "Here's the thing:"
- "...and I'm here for it"

### Corporate Filler
- "Moving forward..." / "Going forward..."
- "At this point in time..."
- "Due to the fact that..." → "because"
- "In order to..." → "to"
- "In the wake of..." / "On the heels of..."
- "In a world where..." / "In an era of..."

### House-Style Banned Phrases
- "sends a clear message to investors"
- "positioning the company to"
- "This development underscores"
- "signaling [noun] to the market"
- "validates the [noun] thesis"
- "amplifies concerns about"

## Tier 3: Banned Structures

### Never Start a Sentence With
- "So," / "Well," / "Now," (when not about time)
- "Look," / "Listen,"
- "Basically," / "Essentially,"
- "Interestingly," / "Notably," / "Importantly,"

### Never End a Sentence With
- "...right?" / "...you know?" / "...if you will"

### Patterns to Avoid
- **"Not just X — it's Y"**: State directly
- **"Fundamentally transforms"**: Describe the actual change
- **Near-synonym stacking**: "comprehensive, sophisticated, and robust" → pick one or none
- **Passive voice hiding agency**: "It was determined..." → name who

## Tier 4: Model C Only (Industry Trend — strictest enforcement)

| Banned | Replace With |
|--------|-------------|
| disruptive / disruption | describe what changed |
| ecosystem | name the companies/products |
| game-changer | describe specific impact with numbers |
| revolutionary | new, first-of-kind, or describe |

| next-generation | name the generation, give specs |

## The Wire-Desk Test

For every sentence: "Would a top wire desk publish this?" YES → keep. NO → rewrite or delete.
